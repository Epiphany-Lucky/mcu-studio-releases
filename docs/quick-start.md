# MCU Studio 快速开始

## 加载配套实验

从左侧选择实验，载入配套 ARM 固件和参考接线后运行。点选 MCU 引脚与模块端点可添加跳线，在接线列表中可以删除跳线。恢复参考接线时核对当前实验与固件使用的引脚。

软件显示的 MCU 端点按 STM32F407ZGT6 封装建立。外设接口配置应与固件寄存器设置一致。例如 USART1 的 PA9/PA10 需要设置为 AF7，SPI1 的 PA5/PA6/PA7 需要设置为 AF5。

## 查找全部物理引脚

主图按封装顶视图引出 LQFP144 的全部 144 个物理脚，包含 114 个 GPIO 和 30 个电源、复位及专用脚。引脚号按 ST DS8626 Rev 12 图 14 和表 7 核对，重复的 VDD/VSS 具有独立编号。[ST 数据手册](https://www.st.com/resource/en/datasheet/stm32f407zg.pdf)

在“芯片引脚”输入物理脚号、GPIO 名称或复用功能，也可按 PA–PH 端口、电源、专用脚筛选。例如搜索 `34` 可找到 PA0，`101` 对应 PA9，`102` 对应 PA10。点选引脚后选择另一端，或使用“添加连线”选择目标端点。接线图支持 100%–400% 缩放及滚动查看。

默认电源网络标为 `3V3` 与 `GND`。17 号 VDD 和 16 号 VSS 等物理端点可用于连接外部模块的电源与地。NRST、BOOT0、PDR_ON、VCAP 等专用脚保留原始用途说明，其当前模型范围通过诊断提示。

## 基础实验

| 实验 | 参考引脚 | 操作 |
|---|---|---|
| GPIO 流水灯 | PF9、PF10 | 运行后观察两个 LED 的变化 |
| 按键与 EXTI | PE4、PE3 | KEY1 外部中断改变 LED1，KEY2 轮询控制 LED2 |
| SysTick | 内核定时器 | CH340 发送 `t` 查看实际中断计数 |
| PWM | TIM3 CH1 PB4 | 观察 1 kHz、25% 占空比与蜂鸣器状态 |
| CH340 | USART1 PA9/PA10 | 在终端发送文本，观察回显 |
| RS485 | USART2 PA2/PA3，DE PD4 | 选择 RS485，发送文本观察固件切换方向并回复 |
| ADC | PA0 | 调整模拟输入，CH340 发送 `a` 获取结果 |
| DAC 回接 | PA4 → PA0 | DAC 3072 输出经连接送入 ADC |
| OLED | PB8/PB9 | 软件 I²C 驱动 128×64 棋盘格 |
| SPI Flash | SPI1 PA5/PA6/PA7，CS PB0 | 读取 JEDEC、擦除、写入和读回 |
| LCD | SPI1 PA5/PA7，CS PB6，DC PB7，RST PB10 | 显示 RGB565 色块与图形 |
| Bootloader | USART1 PA9/PA10 | 发送 `1` 或 `2` 跳转 App，`f` 测试末扇区擦写，`r` 系统复位 |

## PLL 与系统时钟

选择“PLL 与系统时钟”实验并运行。示例使用 HSE 8 MHz，经 PLL 得到 SYSCLK 168 MHz、HCLK 168 MHz、PCLK1 42 MHz、PCLK2 84 MHz。右侧时钟树显示实际频率与 PLL 锁定状态。AHB/APB 分频会作用于对应外设，APB 定时器输入遵循芯片的倍频规则。

CH340 发送 `e`，固件把 SysTick 输入切换到 HCLK÷8。发送 `c` 切换到 HCLK。时钟树的 SysTick 输入行同步显示源与频率。发送 `t` 读取真实中断计数。默认 HSI 为 16 MHz，HSE 为 8 MHz，其他配套时钟固件可从固件入口导入。

## TIM1–TIM14

在定时器面板选择 TIMx，查看实际位宽、时钟、CNT、PSC、ARR、计数方向和通道状态。

| 类型 | 定时器 | 位宽 | 通道 |
|---|---|---|---|
| 高级 | TIM1、TIM8 | 16 位 | 4 个主输出通道，其中前 3 个带互补输出 |
| 通用 | TIM2、TIM5 | 32 位 | 4 |
| 通用 | TIM3、TIM4 | 16 位 | 4 |
| 通用 | TIM9、TIM12 | 16 位 | 2 |
| 通用 | TIM10、TIM11、TIM13、TIM14 | 16 位 | 1 |
| 基本 | TIM6、TIM7 | 16 位 | 更新事件与中断 |

普通定时器菜单示例采用 PLL 168 MHz。输出通道示例为 1 kHz、25% PWM，基本定时器通过更新中断计数演示。CH340 发送 `t` 获取固件计数，TIM2/TIM5 还可发送 `o` 演示 32 位溢出。

TIM1/TIM8 示例提供 10 kHz、设定占空比 40% 的互补 PWM，死区 500 ns、RCR 为 1。按住 K1 可触发刹车并清除 MOE。面板显示实际主/互补输出、MOE、刹车、死区和重复计数配置，展开“最近输出边沿”可查看真实输出事件。CH340 命令如下。

| 命令 | 固件操作 |
|---|---|
| `0` | 关闭主输出与自动输出使能 |
| `1` | 启用主输出与自动输出使能 |
| `a`、`b` | 改写比较值，分别设置 20%、70% 占空比 |
| `u` | 生成软件更新事件 |
| `t` | 读取更新、刹车与 SysTick 中断计数 |

当前计数路径覆盖向上计数与边沿对齐。向下计数和中心对齐配置通过诊断提示。

## 定时器输入捕获

选择“定时器输入捕获”并运行。参考跳线把 PB4 的 TIM3 CH1 输出接入 PA0 的 TIM2 TI1，TIM3 提供 1 kHz、25% PWM。TIM2 CH1 捕获上升沿，CH2 使用交叉输入捕获下降沿，固件通过实际中断计算周期与高电平时间。

在 CH340 发送 `t` 查看 `PERIOD_US`、`HIGH_US`、`RISE` 和 `FALL`。参考信号的周期为 1000 µs，高电平时间为 250 µs。定时器面板选择 TIM2，可查看输入通道模式和 CCR 捕获值。删除 PB4 至 PA0 的跳线后捕获停止，重新连接后继续测量。HSI 与 PLL 两组固件随运行包提供，实际验收结果见同版记录。

## 导入自己的固件

HEX 文件使用其记录的真实地址。BIN 文件需要指定与链接设置一致的基址，常见基址为 `0x08000000`。STM32F407ZG 的内部 Flash 为 1 MiB，主 SRAM 为 128 KiB，CCM 为独立 64 KiB。

多固件入口允许按实际地址装入 Bootloader 和应用。镜像中真实写入的字节需要互不重叠，启动向量应指向已装入的有效程序。工程导出包含固件内容，用户可自行保存和重新载入。

切换模块的接口路径后，按固件配置连好对应引脚。串口 TX 连转换器 RX，串口 RX 连转换器 TX。RS485 还需要方向脚。屏幕、Flash 等模块需要相应电源、地和信号连接。

## 运行与诊断

使用运行、暂停、复位和单步控制执行。诊断面板记录实际启动错误、接线冲突和支持范围相关信息。遇到无输出时可依次检查固件地址、运行状态、模块选配、信号接线和 GPIO 复用配置。

工程文件保存固件和实验配置。重新载入时从选择的向量复位执行。

## 软件更新

从设置进入检查更新。新版可下载时，软件显示进度并校验安装文件，再交接系统安装与重启。更新前保存当前工程。软件下载与更新公告位于公开的 `Epiphany-Lucky/mcu-studio-releases` 仓库。
