# MCU Studio 0.2.0 开发预览

已发现旧版内置更新完成后自动启动失败的情况，从Windows快捷方式正常启动可以恢复。修复版本0.2.1正在验证，实际生产更新记录已补充到验证附件。

面向STM32F407ZGT6的本地固件仿真工作台。源码在私有仓库维护，安装文件、使用说明和更新公告公开提供。

## 本次更新

- 增加器件库。LED、按键、模拟量输入、VCC和GND可重复添加，支持拖动布局、独立接线、改名、颜色与电压参数，以及删除器件及其关联线路。
- 串口、显示、Flash和蜂鸣器接入同一布局管理。LED及按键响应来自真实GPIO、电源网络和固件执行。
- 工程v2保存器件集合、布局与参数，兼容导入0.1版工程。
- 默认采用白底近黑文字、清晰边框、加深的灰色工作区和深色侧栏。新增浅色、深色及跟随系统，保存本机偏好。
- 提供单文件Windows系统MSI，安装资源内嵌，支持自定义路径、修复、升级与卸载，安装及更新通过Windows管理员授权。
- MSI安装通过MSI更新，已有EXE安装沿用EXE通道，下载与安装前核对文件大小及SHA-256。
- 修复首次固件及工程载入的客户端等待窗口，支持Renode冷启动完成后返回实际结果。

## 下载与安装

Windows可下载`MCU-Studio-0.2.0-Setup-x64.msi`并双击安装。发行附件同时提供EXE、Windows便携与本地浏览器包，以及Linux DEB和便携包。保留完整解压目录结构。[安装说明](https://github.com/Epiphany-Lucky/mcu-studio-releases/blob/main/docs/install.md)

## 仿真范围

本版继续提供144个物理引脚、114个GPIO、HSI／HSE／PLL、TIM1–TIM14及28项实验菜单。器件库包含11类已接入模型的器件。TIM计数路径覆盖向上计数与边沿对齐，向下与中心对齐配置有诊断提示。功能级固件执行的详细记录随同版验证文档提供。

## 许可与摘要

附件提供SHA-256清单和Renode1.17.0精确对应源码。运行包保留第三方组件许可，WiX5.0.2原始UI组件的对应源码链接登记在第三方声明中。[第三方声明](https://github.com/Epiphany-Lucky/mcu-studio-releases/blob/main/THIRD_PARTY_NOTICES.md)

## 发行验证

正式构建的6项CI任务全部成功。Windows与Linux分别发现122项单元测试，平台适用用例全部通过，各自完成16项真实ARM固件和26项浏览器验证，JavaScript错误为0。系统MSI通过安装、修复、主要升级、降级阻止及三阶段真实失败回滚，首次EXE迁移和恢复补偿均已验证。完整记录见附件`VALIDATION-0.2.0.md`。

白色主题实测主文字对比度17.767∶1，控件边界4.357∶1，引脚8.825∶1，线路6.499∶1。当前仿真结果来自软件执行环境。
