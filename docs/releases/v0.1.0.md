# MCU Studio 0.1.0 开发预览

2026-11-17

MCU Studio 是独立的 STM32F407 固件仿真工作台。首版使用 STM32F407ZGT6，采用 Apple 风格界面和可编辑原理接线图，在本地执行真实 Keil HEX/BIN。

## 首版功能

- 28 项实验，随包提供 55 份 Keil 镜像及可本地修改、重编译的教学代码。
- 按 LQFP144 物理脚号引出全部144个引脚，支持端点搜索、复用功能查看与缩放接线。
- HSI／HSE／PLL 时钟树、AHB／APB 分频与定时器倍频，联动 SysTick、USART 和定时器。
- TIM1／TIM8 高级定时器，包含互补 PWM、死区、MOE、刹车、AOE、RCR 和中断。
- TIM2～TIM5、TIM9～TIM14 普通定时器，TIM6／TIM7 基本定时器。提供真实接线输入捕获实验。
- CH340 与 RS485 选择、可配置 USART/GPIO AF 路径及方向控制。
- 可选 ILI9341 SPI LCD 与 SSD1306 OLED，画面来自固件实际命令和数据。
- LED、按键、EXTI、SysTick、PWM、ADC、引脚 DAC 和 SPI NOR Flash。
- 多镜像共同装载、Bootloader 跳转、内部 Flash 擦写和系统复位。
- 保存固件、模块、接线、接口及实际 Flash 内容，整体校验后恢复工程。
- 应用内检查更新、下载进度、SHA-256 校验与安装交接。

## 下载

按系统选择 Windows 安装版、Windows 便携版、HTML 本地运行包、Ubuntu/Debian amd64 DEB 或 Linux 便携包。文件摘要在 `SHA256SUMS-0.1.0.txt` 中。第三方对应源码附件为 `renode_1.17.0_source.tar.xz`。

源码仓库由项目所有者私有维护。此公开仓库用于软件分发、公告和使用资料。随包附带教学固件代码、Web 运行资源及第三方许可资料。

## 验证与支持范围

验收包含基础实验、四组替代引脚路径、六种时钟配置、全部普通与基本定时器的实际更新中断，以及TIM1／TIM8互补输出和刹车恢复。Windows、Linux的源码和冻结包均通过16项真实固件链路及22项浏览器验收。93项回归中Windows83项通过、10项Linux专用跳过，Linux93项全部通过。

本版构建提交为`18f2b2a9be7743dffe6925ee12aae9e1c903089f`，CI编号为`43898326990`，五项任务全部成功。Windows正式安装包已完成本机安装、原生窗口、实际LCD像素、工程恢复及2140个安装文件的逐项SHA-256核验。
