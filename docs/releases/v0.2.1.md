# MCU Studio 0.2.1 开发预览

面向STM32F407ZGT6的本地固件仿真工作台。源码在私有仓库维护，安装文件、使用说明和更新公告公开提供。

## 本次修复

修复应用内更新安装完成后，自动重启继承旧引擎临时运行环境而出现Python DLL装载错误的问题。更新helper与桌面启动器均建立新的引擎运行环境，支持安装完成后重新进入工作台。

## 继续提供的功能

- 器件库支持重复添加LED、按键、模拟量输入、VCC和GND，支持拖动布局、独立接线、参数编辑和删除。工程v2保存器件与布局，并兼容导入0.1版工程。
- 默认白色卡片、近黑文字、清晰边框、灰色工作区和深色侧栏，提供浅色、深色及跟随系统并保存偏好。
- 完整144个物理引脚与114个GPIO、CH340／RS485、可选OLED／LCD、HSI／HSE／PLL、TIM1–TIM14及28项实验菜单。固件执行与器件状态来自实际软件仿真模型。
- 定时器计数路径覆盖向上计数与边沿对齐，向下与中心对齐配置提供诊断提示。

## 下载与更新

Windows系统安装提供单文件`MCU-Studio-0.2.1-Setup-x64.msi`，安装及系统范围更新需要管理员授权。已有EXE安装沿用当前用户EXE通道。软件按安装类型选择更新文件，下载及安装前核对文件大小和SHA-256。发行附件同时提供Windows EXE、便携与本地浏览器包，以及Linux DEB和便携包。[安装说明](https://github.com/Epiphany-Lucky/mcu-studio-releases/blob/main/docs/install.md)

更新前保存当前工程，安装完成后由软件自动重启。

## 许可与验收

附件提供SHA-256清单和Renode1.17.0精确对应源码，运行包保留第三方组件许可。[第三方声明](https://github.com/Epiphany-Lucky/mcu-studio-releases/blob/main/THIRD_PARTY_NOTICES.md)

完整CI的6项任务均通过。Windows发现123项测试，通过113项并跳过10项Linux专用用例。Linux发现123项，通过122项并跳过1项Windows专用用例。两平台各16项固件与26项浏览器验收通过。MSI完成安装、修复、主要升级、三阶段失败回滚和EXE迁移恢复。验收记录及正式应用内升级的实际状态见附件`VALIDATION-0.2.1.md`。

白色主题主文字对比度17.767∶1、控件边界4.357∶1、引脚8.825∶1及线路6.499∶1，本补丁沿用该配色。
